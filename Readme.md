# Library Management System

A Library Management System built in Python.

## Features

- Add books
- View books
- Search books
- Save books to JSON
- Load books automatically

## Technologies Used

- Python
- JSON

## Planned Features

- Borrow books
- Return books
- Delete books
- Edit books
- Tkinter GUI
- SQLite database

## How to Run

```bash
py main.py
```
