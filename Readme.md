# 📚 Library Management System

A simple Library Management System built with Python.

## Features

- Add Book
- View Books
- Search Book
- Borrow Book
- Return Book
- Edit Book
- Delete Book
- JSON file storage
- Case-insensitive search
- Git version control

## Technologies Used

- Python 3
- JSON
- Git & GitHub


## Future Improvements

- SQLite database
- PySide6 GUI
- Book IDs
